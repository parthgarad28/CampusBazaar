# 📚 Campus Bazaar

**Pass it on. Save more.**

Campus Bazaar is a student-to-student marketplace where school and college students in India can buy and sell second-hand books, handwritten notes, stationery, gadgets, and other everyday student items, affordably and safely, within their own campus community.

> Formerly known as *Kitaab Kart*.

 **Live demo:** https://campus-bazaar-students-marketplace.ai.studio/

---

## 💡 The Problem

Students spend thousands every year on textbooks, notes, and supplies that are used for just one semester or one academic year, then left unused. Meanwhile, juniors and other students struggle to afford the same items. Existing classifieds platforms are cluttered, impersonal, and not built for students.

## 🎯 The Solution

Campus Bazaar gives students one clean, organized place to:
- **Sell** what they no longer need and earn back some money
- **Buy** what they need at a fraction of the retail price
- **Connect** with other students nearby, from school level to college and competitive exam prep

---

## ✨ Features

- 🛍️ **Buy & Sell Listings:** list items in a few simple steps with photos, price, and condition
- 🎓 **Shop by Level:** School, College, and Competitive Exams
- 🗂️ **Smart Categories:** Textbooks, Notes, Stationery, Calculators & Gadgets, Lab Coats & Uniforms, Hostel Essentials, Novels & Others
- 🔍 **Powerful Search & Filters:** class/year, board (CBSE/ICSE/State), stream, price range, and condition
- 👤 **User Profiles with Profile Pictures:** personalized profiles with avatars, your listings, and ratings
- ❤️ **Wishlist / Saved Items:** bookmark items to come back to later
- 💬 **In-app Chat:** message sellers directly to negotiate and arrange campus meetups
- ⭐ **Seller Ratings & Trust:** build reputation within the student community
- 📱 **Fully Responsive:** mobile-first design with bottom navigation
- 🎞️ **Smooth Motion & Interactions:** animated cards, transitions, and micro-interactions that make browsing enjoyable

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/your-username/campus-bazaar.git

# Go into the project folder
cd campus-bazaar

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open `http://localhost:5173` in your browser.
